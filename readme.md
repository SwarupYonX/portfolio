# Swarup Das — Portfolio

Modern, responsive portfolio website showcasing Cloud Infrastructure, DevOps, and Agentic AI expertise.

🌐 **Live:** [swarup.dev](https://swarupyonx.github.io/portfolio/) (update with your URL)

## ✨ Features

- **Expandable Project Cards** — Click any project to view detailed modal with tech stack, achievements, and links
- **Custom AI-Generated Images** — Unique project visuals created for each featured project
- **Interactive Q&A Section** — Accordion-style FAQ covering experience, certifications, and approach
- **Smooth Animations** — Fade-in effects, modal transitions, and hover interactions
- **Mobile Responsive** — Fully optimized for all screen sizes
- **Contact Form** — EmailJS integration for direct messages
